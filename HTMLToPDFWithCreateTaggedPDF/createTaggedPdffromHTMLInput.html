Adobe PDF Services API

Adobe PDF Services API provides a set of cloud-based operations for working with PDF documents, including converting, combining, compressing, and extracting content from PDF files.

Supported Operations

  • Create PDF from Office documents, images, and HTML
  • Export PDF to Word, Excel, PowerPoint, and image formats
  • Combine multiple PDF files into a single document
  • Compress PDF files to reduce their size
  • Extract text, tables, and figures from PDF documents
  • Apply OCR to scanned documents

Getting Started

To use the Adobe PDF Services API, you need a set of credentials that can be obtained from the Adobe Developer Console. The SDK is available for .NET, Java, Python, and Node.js.
